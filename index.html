          Kiến Trúc Hệ Thống 3 Tầng (3-Tier Concept) Theo Paper
        

        
Mô hình phân tách giữa giao diện trình duyệt, cầu nối API và máy chủ thực thi Linux (Hình 5 trong bài báo của Alhogail & Alkahtani, 2024).


        

          
          
          

            

              
            

            
1. Presentation Tier

            
Google Chrome Extension

            
Giao diện người dùng trên trình duyệt, gửi trigger kiểm thử qua REST API và hiển thị kết quả báo cáo.

          


          
          

            
            JSON / HTTP REST
          


          
          

            

              
            

            
2. Application Tier

            
PHP API Service

            
Nhận request, validate regex tránh command injection, điều phối tác vụ và tổng hợp kết quả.

          


          
          

            

              
            

            
3. Data & Exec Tier

            
Ubuntu Linux Server

            
Thực thi Nmap, Sublist3r, FastFuz, SearchSploit và lưu trữ exploit scripts.
